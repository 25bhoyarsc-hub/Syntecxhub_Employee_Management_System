# Employee Management System

A simple and user-friendly Employee Management System built using React.js, Node.js, Express.js, and MongoDB.

## Features

- Add Employee
- View Employee
- Update Employee
- Delete Employee
- Manage Employee Records
- MongoDB Database Integration
- REST API
- Simple and Attractive UI
- Responsive Design

## Technologies Used

- React.js
- JavaScript
- CSS
- Axios
- Node.js
- Express.js
- MongoDB
- Mongoose
